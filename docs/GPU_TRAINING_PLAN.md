# 외부 GPU 학습 계획

현재 단계에서는 모델을 다운로드하거나 학습하지 않습니다. RAG 품질과 평가 기준을
먼저 확립한 뒤, 말투·지시 수행 개선이 필요한 경우에만 LoRA/QLoRA를 검토합니다.

향후 단계:

1. 사용 권한과 품질이 확인된 지시 데이터셋을 별도로 준비합니다.
2. 지원 언어와 하드웨어에 맞는 Llama 계열 Instruct 기반 모델을 선정합니다.
3. 외부 GPU 서버에서 재현 가능한 환경과 비밀정보 관리 방식을 구성합니다.
4. LoRA 또는 메모리 효율적인 QLoRA로 소규모 실험을 수행합니다.
5. 사실성, 출처 충실도, 다국어 품질, 안전성 평가 후 어댑터를 승인합니다.
6. 추론 어댑터를 `BaseLLM` 구현으로 연결하고 RAG 근거 제한을 유지합니다.

역사 사실 자체를 모델에 암기시키는 것이 목표가 아니며, 검증된 사실의 갱신은 RAG
데이터 계층에서 수행합니다. 개인 대화 기록도 튜닝 데이터에 자동 편입하지 않습니다.
