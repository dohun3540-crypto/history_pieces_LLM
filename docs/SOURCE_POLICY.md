# 자료 출처 및 이용 정책

## 사용할 수 있는 자료

공식 기관·공공 기록관·박물관·도서관·학술 출판물처럼 출처와 책임 주체를 추적할
수 있는 자료를 우선합니다. 웹에서 열람할 수 있다는 사실만으로 이용 허락이 있다고
판단하지 않습니다. 출처, 권리 상태, 라이선스 원문, 접근일을 자료별로 확인합니다.

## 저작권 상태별 기본 정책

| 상태 | RAG 기본값 | 모델 학습 기본값 | 필요한 확인 |
|---|---:|---:|---|
| `public_domain` | 개별 확인 후 허용 가능 | 별도 확인 후 허용 가능 | 퍼블릭 도메인 근거 |
| `open_license` | 라이선스 조건 확인 후 허용 가능 | 학습 허용 범위를 별도 확인 | 라이선스명·URL·표시 조건 |
| `permission_granted` | 허가 범위 안에서 허용 가능 | 학습을 명시적으로 허가한 경우만 가능 | 허가 기록 |
| `restricted` | 금지 | 금지 | 권리자 추가 허가 |
| `unknown` | 금지 | 금지 | 권리 상태 조사 |

`allowed_for_rag`, `allowed_for_training`, `redistribution_allowed`는 서로 다른
권리로 기록합니다. RAG 사용 허락은 모델 가중치 학습이나 원문 재배포 허락을
의미하지 않습니다.

## 출처 표시

표시 의무가 있는 자료는 `attribution_required=true`와 완전한
`attribution_text`를 기록합니다. 표시 문구가 없으면 검증에 실패합니다. 각 청크는
`document_id`, 제목, 원 출처와 라이선스 메타데이터를 유지해야 합니다.

## 검수 전 사용 금지

등록과 기계적 처리는 이용 승인이 아닙니다. 역사 사실·출처·권리 조건을 사람이
검수하여 `review_status=reviewed`가 된 자료만 서비스용 RAG 색인에 사용할 수
있습니다. `draft`, `extracted`, `cleaned`, `metadata_added`, `rejected` 자료는
색인하지 않습니다.
