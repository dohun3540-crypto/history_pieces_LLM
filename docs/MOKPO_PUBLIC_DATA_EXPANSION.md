# 목포 근대역사 공식 자료 후보 확대 조사

- 조사일: 2026-07-30
- 조사 방식: 공식 검색 결과의 제한적 탐색과 공식 상세 페이지 확인
- 제외: 공공데이터포털, 비공식 사이트, 로그인 우회, 대량 다운로드, RAG 색인
- 결과: 고유 상세 레코드 51건(후보 36건, 참고 전용 15건)

## 결론

목표 150건에는 도달하지 못했다. 소량 GET과 공개 검색 결과만으로 공식 식별자,
본문, 직접 관련성을 함께 확인할 수 있었던 자료는 51건이었다. 국가기록원과
공식 도서관은 검색 목록에서 상세 원문 및 자료별 권리까지 추적하기 어려웠고,
한국사데이터베이스는 현재 감사 기록상 일반 수집 User-Agent의 robots 규칙이
전체 차단으로 확인되어 후보 확대에 사용하지 않았다. 숫자를 채우기 위한
간접 언급, 목록 페이지, 중복 레코드는 추가하지 않았다.

모든 레코드는 `candidate` 또는 `reference_only`이며, `allowed_for_rag`와
`allowed_for_training`은 모두 `false`다. 개별 이용조건의 사람 검수가 끝나기
전에는 승인하거나 수집할 수 없다.

## 권리 판정

- 독립기념관 및 국가유산포털: 공식 본문은 확인했으나 개별 자료의 공공누리
  유형 또는 RAG 가공 허락을 확인하지 못해 `unknown`으로 유지했다.
- 목포문화관광 3건은 페이지 하단 공공누리 제4유형 표시를 확인했다.
  변경금지 조건이 정제·청크화·요약과 충돌할 수 있어 승인 추천하지 않았다.
- 이미지·사진·도면은 본문과 별개 권리 검토가 필요하다.
- RAG 허용 여부와 모델 학습 허용 여부는 독립적으로 검수해야 한다.

## 재현 및 검증

`python scripts/build_mokpo_source_audit.py`는 네트워크 없이 확인된 상세 URL
목록을 JSONL과 요약 JSON으로 다시 생성한다. 이 스크립트는 다운로드, 승인,
manifest 변경 또는 인덱싱을 수행하지 않는다.
