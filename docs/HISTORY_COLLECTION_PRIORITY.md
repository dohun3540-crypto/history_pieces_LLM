# 목포 역사 데이터 수집 우선순위

이 계획은 `reports/history_data_audit.json`의 현재 파일·manifest 집계를 기준으로 한다. 자동 주제 분류는 추정이며, 실제 역사성·권리·production 적합성은 사람이 검토한다. 외부 수집은 이 감사 작업에서 수행하지 않았다.

## 우선순위 1

- 목포 해관: 관련 1건, 기관 1곳, production 승인 0건이다.
- 외국인 거류지·조계지: 관련 1건, 기관 1곳, production 승인 0건이다.
- 구 일본영사관: 개발 검증용 1건뿐이며 원문은 `remote_only`, 권리는 검토 대기다.
- 근대 항만과 철도: 관련 3건으로 추정되지만 모두 provisional이고 직접성이 낮은 결과가 포함되어 수동 검토와 독립 자료 보강이 필요하다.

## 우선순위 2

- 목포 개항: 9건으로 추정되지만 모두 provisional·권리 미확정이며 한 기관 비중이 67%다. 신규 수량보다 독립 출처와 권리 명확성이 우선이다.
- 동양척식주식회사 목포지점: 5건으로 추정되지만 80%가 한 기관이고 production 승인 자료는 없다.
- 목포 근대역사문화공간: 4건, 기관 2곳이나 전부 권리 검토가 끝나지 않았다.

## 우선순위 3

- 일제강점기 목포의 산업과 도시 변화: 키워드상 22건이지만 91%가 한 기관에 편중되고 인물사 문서의 간접 언급이 다수여서, 도시·산업을 직접 다루는 자료인지 수동 검토가 먼저다.
- 관련 인물, 노동, 교육, 생활사는 핵심 8개 주제의 최소 독립 출처가 확보된 뒤 확장한다.

## 다음 수집 배치 제안

첫 배치는 총 16건을 권장한다.

| 주제 | 권장 건수 | 목적 |
|---|---:|---|
| 목포 해관 | 4 | 최소 5건과 기관 다양성 확보 |
| 외국인 거류지·조계지 | 4 | 최소 5건과 직접 자료 확보 |
| 구 일본영사관 | 3 | 기존 개발 자료 외 독립 근거 확보 |
| 근대 항만과 철도 | 3 | 직접 주제 자료와 독립 출처 보강 |
| 목포 근대역사문화공간 | 2 | 최소 5건 이상 및 출처 보강 |

- 한 기관당 최대 3건, 불가피한 경우에도 5건을 넘기지 않는다.
- 한 주제당 최소 2개 독립 기관을 목표로 한다.
- 로그인, 캡차, 유료벽, 이용조건 불명확 자료는 제외한다.
- 원문과 추출 텍스트는 별도 경로에 저장하고 각각 hash를 기록한다.
- manifest의 `review_status`는 `draft` 또는 기존 정책상 초기 상태로 유지한다.
- 권리 상태가 unknown이면 RAG·학습·재배포를 허용하지 않는다.
- 사람 검토 전 `production_approved`를 변경하지 않는다.

## 40~80건 데모 데이터셋과의 차이

fixture 제외 manifest 항목은 52건이므로 단순 보유 수량은 목표 범위에 들어간다. 그러나 48건은 provisional, 3건은 production 미승인 개발 검증용, 1건은 rejected이며 production 사용 가능 자료는 0건이다. 따라서 신뢰·권리·사람 검토를 통과한 데모 데이터셋 기준으로 최소 목표 40건까지 40건, 상한 80건까지 80건이 남아 있다. 이 차이는 전부 신규 수집으로 채우는 수치가 아니다. 기존 51개 미승인 후보를 먼저 수동 검토해 승격 가능·reference only·rejected로 나눈 뒤 실제 신규 수집량을 다시 계산해야 한다.

## 수집 전후 최소 자동 검사

`python scripts/audit_history_data.py`를 수집 전후 동일 옵션으로 실행하고 JSON diff를 검토한다. 최소 통과 조건은 document/source URL 중복 없음, 원문·manifest·chunk·index 연결성, 필수 의미 필드 누락 확인, 빈/짧은 본문 경고 검토, 권리 미확정 자료의 production 제외, 기관 편중 확인이다.
