# 목포 근대역사 자료 RAG 이용 허락 문의 계획

작성일: 2026-07-30

## 문의 목적과 범위

비상업적 연구·교육용 목포 근대역사 챗봇에서 기관의 공식 설명문·기록물을 RAG 검색 근거로
사용할 수 있는지 서면으로 확인한다. 원문은 모델 학습에 사용하지 않으며, RAG 허락과 모델
학습 허락을 하나의 동의로 간주하지 않는다.

## 공통 질문

1. 지정한 URL과 자료를 자동 또는 수동으로 수집할 수 있는가?
2. 원문을 내부 저장하고 Unicode 정규화, 메뉴 제거, 문단·청크 분할할 수 있는가?
3. 청크를 임베딩하여 비공개 검색 인덱스에 저장할 수 있는가?
4. 검색된 일부 문장을 LLM의 참고 문맥으로 전달하고 자연어로 요약할 수 있는가?
5. 기관명, 문서 제목, 원본 URL, 접근일을 표시하는 방식이 충분한가?
6. 원문 일부를 답변에 인용할 때 허용되는 분량과 표기 문구는 무엇인가?
7. 연구용 내부 시험과 일반 공개 서비스의 허용 범위가 다른가?
8. 상업화할 경우 추가 허락 또는 협약이 필요한가?
9. 이미지, 도면, 첨부 PDF, OCR 텍스트의 권리는 각각 어떻게 다른가?
10. 이용 허락의 유효기간, 철회·갱신 절차와 담당 부서는 어디인가?

## 회신 기록 방법

- 기관명, 담당 부서, 담당자 직위 또는 이름
- 문의 발송일과 회신일
- 허락 대상 URL 및 문서 목록
- 허용된 수집 방식, 저장 범위, 가공 범위
- RAG·임베딩·공개 서비스 허용 여부
- 정확한 출처표시 문구
- 상업 이용 및 모델 학습 허용 여부
- 유효기간, 철회 조건, 원문 보관 조건
- 이메일·공문 등 증빙 파일의 내부 보관 위치와 해시

구두 답변만 받은 경우에는 승인 상태로 바꾸지 않고 서면 회신을 요청한다. 자료 목록에 없는
문서는 회신을 확대 적용하지 않는다.

## 다음에 실제 문의할 우선 기관 3곳

1. **목포시 문화예술과 및 관광과**: 지역 공식 본문을 가장 직접적으로 관리한다.
2. **국가유산청 국가유산포털 담당 부서**: 상세 설명과 안내판 문안을 구조적으로 제공한다.
3. **목포근대역사관**: 전시 해설·도록·패널 등 고품질 설명 자료의 저작권 관계를 확인할 수 있다.

국가기록원과 국사편찬위원회는 위 세 기관 회신 양식과 범위를 정리한 뒤 2차로 문의한다.
