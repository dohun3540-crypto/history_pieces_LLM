# 역사 자료 데이터 가이드

현재 `data/sample` 파일은 파이프라인 테스트용이며 역사적 사실을 담지 않습니다.
실제 자료 도입 시 다음 원칙을 적용합니다.

- 박물관, 기록관, 정부·지자체, 학술 출판물 등 출처를 우선합니다.
- 문서마다 안정적인 `id`, 정확한 `title`, 추적 가능한 `source`, `language`를 둡니다.
- 원문 작성자, 발행일, 열람 URL, 이용 허락, 검증 상태를 metadata에 기록합니다.
- 해석이 갈리는 내용은 단정하지 않고 관점과 출처를 함께 보존합니다.
- OCR 결과는 원문 대조와 인명·지명·연도 검수를 거칩니다.
- 개인정보와 저작권을 검토한 자료만 수집합니다.
- 대화 내용은 사용자 동의 없이 자료나 학습 데이터에 합치지 않습니다.

대용량 원문 데이터는 Git에 커밋하지 않고 별도 버전 관리 저장소를 사용합니다.
