# 공공데이터 역사·문화 자료 조사 보고서

조사일: 2026-07-30

## 권리 판정 원칙

공공데이터포털 상세 화면의 `이용허락범위`를 데이터셋 단위 근거로 사용했다.
`이용허락범위 제한 없음`은 RAG용 가공 가능 후보로 보되, AI 모델 학습을 명시적으로 허용하는
문구는 아니므로 `allowed_for_training=false`를 유지한다. 실제 사용 전에는 API 응답의
개별 레코드에 제3자 저작권·별도 이용조건이 포함되는지 다시 검사해야 한다.

## 제외 자료

- 목포 근대역사관 예산, 관람객, 시설 운영 현황: 역사 설명 본문이 아니므로 제외.
- 박물관 시설 통계: 위치·운영 통계일 뿐 역사 서술 자료가 아니므로 제외.
- 공공누리 제3·4유형 데이터: 기본 RAG 가공 후보에서 제외.
- 목포 레코드나 설명 필드가 확인되지 않은 전국 단위 데이터는 실제 응답 확인 전 색인하지 않는다.

## 파일럿 권장 순서

1. 국문 관광정보 서비스에서 `목포근대역사관`, `목포`, `구 일본영사관`을 키워드 조회한다.
2. 반환된 각 콘텐츠의 소개정보, 저작권 코드, 콘텐츠 ID와 원본 URL을 저장한다.
3. 국가유산 공간정보에서 목포 국가유산의 설명 필드 제공 범위를 확인한다.
4. 독립운동가 인명사전에서 목포 출신·목포 활동 인물을 조회하고 상세 본문 반환 여부를 확인한다.
5. 제3자 권리나 별도 조건이 한 건이라도 나타나면 해당 레코드를 `unknown`으로 격리한다.
