# 기관별 자료 이용 허락 요청 계획

## 공통 질의

비상업적 연구·교육 목적의 목포 근대역사 RAG 챗봇에서 원문을 그대로
재배포하지 않고, 텍스트를 정제·분할·임베딩하여 검색 근거로 사용할 수 있는지
문의한다. 답변에는 기관명, 문서 제목, 공식 URL과 식별자를 표시하며 원문은
모델 파인튜닝에 사용하지 않는다.

다음 항목을 서면으로 확인한다.

1. 허용되는 자료 범위와 수집 방식
2. 본문 저장, 정제, 청크화, 임베딩 허용 여부
3. 생성 답변의 근거로 요약·인용하는 행위의 허용 여부
4. 필수 출처표시 문구
5. 이미지·사진·도면의 별도 권리
6. 비상업 공개 서비스 범위와 별도 신청/협약 필요 여부
7. RAG와 별개로 모델 학습 이용 가능 여부

## 우선 문의

| 순위 | 기관 | 대상 | 핵심 위험 |
|---:|---|---|---|
| 1 | 독립기념관 | 한국독립운동정보시스템 인명사전 41건 | 개별 본문 재사용·청크화 조건 미확인 |
| 2 | 국가유산청 | 국가유산포털 상세 6건 및 관련 간행물 | 본문·사진 권리 분리 필요 |
| 3 | 목포시 | 목포시사, 역사관, 문화관광 상세 | 확인 자료가 제4유형이라 변경금지 충돌 |
| 4 | 국가기록원 | 기록물 상세·미리보기·원문 | 개별 기록물 및 제3자 권리 |
| 5 | 국립중앙도서관·국회도서관 | 서지·공개 원문 | 열람 가능과 재사용 가능의 구분 |
| 6 | 국립해양문화유산연구소 | 항만·해양 관련 간행물 | 목포 근대사 직접 관련 범위와 이용조건 |

## 답변 기록 기준

기관 회신은 날짜, 담당 부서, 허용 범위, 제한 조건, 출처표시 문구를 원문
그대로 감사 기록에 보존한다. 구두 답변만으로 승인하지 않으며, 모델 학습
허락이 명시되지 않으면 `allowed_for_training=false`를 유지한다.
