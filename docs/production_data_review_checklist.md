### KOGL Type 4 / 공공누리 제4유형 추가 검토

KOGL Type 4를 자동으로 사용 가능하다고 판정하지 않는다. 다음 사항을 개별 자료에 대해 확인하며, 불명확하면 `license_review_required`로 유지한다.

- [ ] 변경금지 조건이 chunking에 적용되는 방식
- [ ] 요약·문장 분할·embedding 허용 여부
- [ ] 필요한 출처 표시 형식
- [ ] 서비스 응답에서 허용되는 이용 범위
- [ ] 필요 시 권리자 또는 담당 기관에 확인했으며 근거를 보존했다.

이 문서와 preflight 코드는 법적 결론을 대신하지 않는다. 최종 판단은 권리 정보와 기관 정책을 확인한 담당자가 내린다.

## 6. Schema mapping

| 목포 데이터 필드 | Main schema 필드 | 처리 구분 | 확인 사항 |
|---|---|---|---|
| `id` | `document_id` | 사람 확인 필요 | ID 충돌 및 추적 관계 확인 |
| `title` | `title` | 자동 복사 후보 | 원문 제목과 동일한지 확인 |
| `source.institution` | `publisher` 또는 기관 필드 | 사람 확인 필요 | 발행처와 소장·제공기관 구분 |
| `source.url` | `source_url` | 자동 복사 후보 | canonical URL 및 직접 접근 확인 |
| `source.license` | `license_name`, `license_url`, 권리 필드 | 사람 확인 필요 | 라이선스 이름만으로 권리 값을 추정하지 않음 |
| `review_status` | `review_status` | 사람 확인 필수 | `verified`를 `reviewed`로 자동 변환하지 않음 |
| `facts[].evidence_quote` | 근거·본문 metadata | 사람 확인 필요 | claim 연결과 최소 인용 범위 확인 |
| `primary_topic` | 주제 metadata | 자동 복사 후보 | main 허용값과 의미 일치 확인 |
| `raw_path` 또는 `local_path` | `local_path` | 사람 확인 필수 | 파일 존재, raw 루트 내부, hash 확인 |

`자동 복사 후보`도 import 전 사람이 원문과 값을 확인해야 한다. 매핑 도구는 누락값, 검수 상태, 라이선스 판단을 생성하지 않는다.
