# 세션 관리

development CLI 세션은 `.runtime/development/sessions.json`에 저장된다.
`.runtime`은 Git에서 제외되며 production 데이터 경로와 공유하지 않는다.
테스트는 임시 디렉터리 또는 메모리 저장소만 사용한다.

- session_id가 없으면 UUID 기반 새 세션 생성
- 존재하는 session_id는 최근 대화 문맥 재사용
- 존재하지 않는 session_id는 오류 없이 새 세션 생성
- 기본 최근 8턴 유지
- 한도를 넘긴 과거 발화는 모델 생성 없이 원문 일부를 제한 길이 요약 영역에 보존
- reset은 해당 세션만 제거
- 존재하지 않는 세션 reset은 `reset=false`

세션에는 사용자 질문과 생성 답변만 저장한다. 모델 가중치를 갱신하거나 대화를
학습 데이터에 자동 추가하지 않는다. 운영에서는 별도 저장소와 보존·개인정보
정책을 마련하기 전까지 장기 저장을 활성화하지 않는다.
