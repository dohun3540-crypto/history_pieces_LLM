# 목포시청·목포문화관광 RAG 이용 허락 문의문

제목: 목포 근대역사 비상업적 연구·교육 챗봇의 공공자료 RAG 이용 가능 범위 문의

안녕하세요.

저희는 목포 근대역사를 국내외 이용자에게 안내하기 위한 비상업적 연구·교육 목적의 챗봇
프로토타입을 개발하고 있습니다. 챗봇이 역사 사실을 임의로 생성하지 않도록, 목포시와
목포문화관광이 제공하는 공식 설명문을 검색 증강 생성(RAG)의 근거로 이용하고자 합니다.

예정된 처리 방식은 다음과 같습니다.

- 원문을 내부 저장하되 사용자에게 원문 전체를 재배포하지 않습니다.
- 메뉴·푸터 제거, Unicode 정규화, 문단 분할과 청크화를 수행합니다.
- 청크를 임베딩하여 검색 인덱스에 저장합니다.
- 검색된 부분만 답변 작성의 참고 문맥으로 사용합니다.
- 답변에는 기관명, 자료 제목, 원본 URL과 필요 시 접근일을 표시합니다.
- 해당 원문은 Llama 등 생성 모델의 학습·미세조정 데이터로 사용하지 않습니다.

위 방식의 RAG 이용이 가능한지와 함께 다음 사항을 서면으로 안내해 주시면 감사하겠습니다.

1. 허용되는 수집 방식과 요청 빈도
2. 내부 저장, 정제, 청크 분할 및 임베딩 허용 여부
3. 검색 근거로 활용하고 자연어로 요약하는 행위의 허용 여부
4. 필요한 정확한 출처표시 문구
5. 인용 가능한 범위와 이미지·첨부파일의 별도 조건
6. 연구용 시험 및 일반 공개 서비스의 허용 범위
7. 향후 상업화 시 별도 협의 필요 여부
8. 별도 신청서, 공문 또는 협약 필요 여부
9. 허락의 유효기간과 변경·철회 통지 방법

허락은 위에 열거한 자료에 한해 적용되는 것으로 이해하고, 다른 자료에는 자동 확대 적용하지
않겠습니다.
