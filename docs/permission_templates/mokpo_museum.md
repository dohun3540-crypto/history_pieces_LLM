# 목포근대역사관 RAG 이용 허락 문의문

제목: 목포근대역사관 전시 해설·도록 자료의 비상업적 RAG 이용 문의

안녕하세요.

목포 근대역사를 안내하는 비상업적 연구·교육용 챗봇을 개발하고 있습니다. 근대역사관의 전시
해설, 안내문, 도록 또는 공개 웹 설명을 사실 근거로 활용하고자 하며, 아래 자료의 권리관계와
이용 가능 범위를 문의드립니다.

- [전시·도록·문서 제목, 작성연도, URL 또는 관리번호]

원문 전체를 공개 재배포하지 않고, 내부에서 정제·문단 분할·청크화·임베딩한 뒤 검색된 일부만
답변의 근거로 사용합니다. 답변에는 목포근대역사관, 자료 제목, 원본 URL 또는 관리번호를
표시합니다. 원문은 생성 모델 학습이나 미세조정에 사용하지 않습니다.

다음을 확인해 주시기 바랍니다.

1. 역사관이 해당 텍스트와 이미지의 저작재산권을 보유하는지
2. 외부 집필자·기증자·촬영자 자료가 포함되어 별도 허락이 필요한지
3. 내부 저장, OCR, 정제, 청크 분할과 임베딩이 가능한지
4. RAG 검색 문맥 및 요약 답변으로 이용할 수 있는지
5. 필수 출처표시 문구와 인용 분량
6. 비상업적 공개 서비스가 가능한지
7. 신청서·공문·협약 및 유효기간이 필요한지

서면으로 허용된 자료만 사용하며 허락 범위를 다른 전시나 자료에 확대 적용하지 않겠습니다.

감사합니다.
