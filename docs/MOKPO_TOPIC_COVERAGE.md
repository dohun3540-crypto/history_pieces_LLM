# 목포 근대역사 주제 커버리지

## 현재 강점

| 주제 | 상태 | 근거 |
|---|---|---|
| 독립운동·학생운동 | 높음 | 독립기념관 공식 인명사전 상세 레코드 |
| 정명여학교·영흥학교·목포공립상업학교 | 높음 | 학생운동 참여자 상세 본문 |
| 목포 4·8 만세운동 | 높음 | 주도자·참여자 복수 상세 본문 |
| 근대역사문화공간·근대 건축 | 중간 | 국가유산포털과 목포문화관광 상세 페이지 |
| 동양척식주식회사 목포지점 | 중간 | 목포근대역사관 2관 공식 설명 |
| 목포 해관·세관 | 낮음 | 국가유산 상세 1건 |

## 부족한 주제

- 개항과 목포항의 행정·경제 자료
- 무안감리서와 목포 이사청의 1차 기록
- 목포부 행정 및 근대 도시계획 문서
- 금융·철도·해운·노동 생활사의 공식 간행물
- 일제강점기 생활사와 해방 전후 도시 변화

독립운동 인명 레코드가 전체 후보를 과도하게 차지하므로, 다음 확대 조사에서는
국가기록원 기록물 철·건 상세 식별자, 국가유산청 간행물, 목포시사 권별 원문,
국립중앙도서관 공식 서지 식별자를 우선 확보해야 한다.

## 검수 우선순위

1. 직접 관련이며 본문이 긴 국가유산·목포시 설명
2. 목포에서 실제 활동이 확인되는 독립운동 인명 레코드
3. 목포 사법·수감 경로만 언급하는 `reference_only`

`reference_only`는 우선 검수 50건 산정에 포함하지 않으며, 별도 목포 본문이나
원기록과 연결될 때만 후보로 승격할 수 있다.

## 첫 파일럿 주제 구성안

권리 서면 허락을 전제로 다음 5개 축을 한 건 이상 포함한다.

1. 도시 형성: 목포 근대역사문화공간
2. 항만·행정: 목포세관 구 목포지점 터와 세관창고
3. 상업·금융: 구 목포 화신연쇄점
4. 독립운동: 곽우영 또는 서상봉 인명사전
5. 학교·교육: 김옥실·김옥남·오상록 가운데 1~3건

현재는 모두 `allowed_for_rag=false`이며 이 구성안은 수집 승인이 아니다.
