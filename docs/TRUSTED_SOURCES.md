# 신뢰 출처 안내

`data/source_catalog/seed_sources.json`은 원문이 아니라 공식 출처의 이름, 기본
URL, 운영 기관, 신뢰도, 확인할 정책 URL과 제한된 탐색 진입점만 보관합니다.

## 신뢰도 등급

- A: 국가·지방자치단체, 국가기록기관, 공식 공공저작물 플랫폼의 1차 자료·공식 설명
- B: 공공 학술 플랫폼, 오픈액세스 저장소, 등재 학술자료
- C: 출처 추적은 가능하지만 기관·저자·검증 수준을 추가 확인해야 하는 자료
- D: 출처나 책임 주체가 불명확하여 기본 후보에서 제외되는 자료

A와 B만 기본 검수 우선 RAG 후보가 될 수 있습니다. 신뢰도는 저작권 허가나 사실
검수 완료를 뜻하지 않습니다. 등급이 A여도 `reviewed` 승인과 자료별 이용조건 확인
전에는 서비스 색인할 수 없습니다.

국사편찬위원회는 자료 소장처에 따라 별도 허가가 필요할 수 있음을 안내하고,
국가기록원과 목포시는 저작물별 공공누리 유형을 확인하도록 안내합니다. 공공누리
역시 유형마다 출처 표시, 상업 이용, 변경 허용 범위가 다르므로 자동으로 허가를
추정하지 않습니다.
